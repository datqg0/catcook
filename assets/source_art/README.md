# Generated source art

These transparent atlases are the source images for the current illustrated food icons and animation frames.

- `food_icon_atlas.png` supplies the sixteen files in `../foods/`.
- `bartender_sheet_v3.png` supplies `../animations/bartender_v2/`.
- `bake_sheet_v3.png` supplies `../animations/bake_v2/`.
- `chop_sheet_v2.png` supplies `../animations/chop_v2/`.
- `maneki_sheet_v2.png` supplies `../animations/maneki_v2/`.

The game loads the cropped PNG frames. Preview GIFs are in `../animations/` and are not used by the renderer.
