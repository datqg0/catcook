# 🍜 Cozy Midnight Diner - 24/7 Interactive Livestream Game

> **Game Nấu Ăn Pixel Art Tương Tác Dọc (9:16 - 720x1280) Phát Sóng Trực Tiếp YouTube 24/7**

---

## ⚡ Khởi động nhanh (Quick Start)

### 1. Cài đặt thư viện:
```bash
pip install -r requirements.txt
```

### 2. Khởi chạy game & bàn điều khiển:
```bash
# Khởi chạy game chính:
python main.py

# Chạy xem trước cục bộ, không bật các tích hợp ngoài:
python main.py --preview

# Hoặc khởi chạy game kèm bàn điều khiển Studio Controller:
python main.py --studio
```

---

## 🎮 Phím tắt điều khiển tại chỗ
- `1` - `9`, `0`: Đặt nhanh 10 món ăn đặc sắc (Ramen, Pizza, Tacos, Boba, Parfait, Curry...)
- `SPACE` / `Y`: Cổ vũ `!yum` (Bắn tim bay + tiếng pop)
- `T`: Tặng tip `!tip 100` (Chuông tiền reo + pháo hoa confetti)
- `M`: Mở bảng thực đơn 16 món (`!menu`)
- `C`: Bật khung gõ lệnh chat tự do (ví dụ `!cook waffles`)
- `V`: Bật/Tắt bot dat giả lập người xem (Viewer Simulator)
- `O`: Mở bàn điều khiển đồ họa **Studio Controller**
- `ESC`: Thoát game
